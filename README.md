# Open Today Larimer

This started as a separate street-day experiment. It is now two buttons on the **Resources** home screen of [Self-Reliance FoCo](https://github.com/TheMilkmanJ/SelfReliance-FoCo):

- **Trash day** — Fort Collins Republic weekday, holiday delay, Loveland Recollect, and hauler numbers for Estes Park, Berthoud, and Wellington.
- **Open now** — meals, showers, beds, and indoor heat/AC that are supposed to be open today.
